# Restricted Enrollment is granted onto a named Offering

On a Restricted Course, Enrollment is granted onto an Offering, not onto the Course. LMS Admin may grant any Offering; the Facilitator of that Offering may grant that Offering only. If the Course has named Offerings, grant must name one of them — not the default Offering. The default remains the seam for an academy with no named runs.

We rejected self-enroll into a Kelas, dumping a roster onto `code=default` when Kelas A/B exist, and a third Dosen role (ADR 007, ADR 011).
