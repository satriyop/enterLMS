# The Restricted OpenClaw Course reuses the public intro via a Learning Path

Administrasi Agen OpenClaw requires Pengenalan Agen AI first. That intro is the same Open Course anyone may take, not a private copy.

The Learning Path is how we enforce the order. It is not publicly enrollable: Path enrollment is granted by LMS Admin. Otherwise anyone who finished the free intro would unlock OpenClaw. Completing the Open Course is necessary for the Path and not sufficient on its own.

We rejected a one-course “Path”, a separate private orientation, and putting both Courses on one Path that the public can join.
