# Operators reuse the public intro Course via a Learning Path

Operators must complete Pengenalan Agen AI before Administrasi Agen OpenClaw. That intro is the same Open Course the public takes, not a private copy.

The Learning Path is how we enforce the order. It is not publicly enrollable: Path enrollment is granted by LMS Admin. Otherwise anyone who finished the free intro would unlock OpenClaw. Completing the Open Course is necessary for an Operator and not sufficient for the public.

We rejected a one-course “Path”, a separate private orientation just for Operators, and putting both Courses on one Path that the public can join.
