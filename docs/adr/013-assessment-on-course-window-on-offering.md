# Assessment belongs to the Course; the Offering times the attempt

The same Assessment is shared by every Offering of a Course. An Offering may set when that Assessment can be attempted. A Grade Proposal is accepted by the Facilitator of the attempt’s Enrollment Offering (LMS Admin if none is assigned).

We rejected copying Assessments per Kelas (soal drift) and one global window for all Offerings (Kelas A Tuesday / Kelas B Wednesday cannot differ).
