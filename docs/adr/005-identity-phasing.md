# Local registration now; Enteraksi login later

A Learner is not defined as an Enteraksi account. Public Learners register as EnterLMS users. Operators in this phase are also local users, created or enrolled by LMS Admin.

Unified Enteraksi login comes later, and must exist before Tenant Admins take Restricted Courses as Enteraksi-linked people. We rejected blocking the first Courses on an IdP, sharing a user database, and letting every Enteraksi user sign in here.
